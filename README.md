# Embedded Hardware Projects

This repository groups the nine embedded hardware projects maintained by Even-lwx.
Each project remains an independent Git repository and is included here as a Git submodule.

| Project | Repository |
| --- | --- |
| AD7682 | https://github.com/Even-lwx/AD7682 |
| Triple 1S Battery Charger | https://github.com/Even-lwx/Triple-1S-Battery-Charger |
| QI5W-R-Ver2.0 | https://github.com/Even-lwx/QI5W-R-Ver2.0 |
| ADS124S08 RTD Acquisition | https://github.com/Even-lwx/ADS124S08_RTD_Acq |
| STM32F103RCT6 Minimal System Board | https://github.com/Even-lwx/STM32F103RCT6-Minimal-System-Board |
| HookWeightModule | https://github.com/Even-lwx/HookWeightModule |
| QiRec-5-T | https://github.com/Even-lwx/QiRec-5-T |
| QiRec-5-R | https://github.com/Even-lwx/QiRec-5-R |
| UML244R | https://github.com/Even-lwx/UML244R |

Clone the complete collection with:

```sh
git clone --recurse-submodules https://github.com/Even-lwx/lwx-embedded-hardware-projects.git
```
