# 工程清单生成工具

`build.mjs` 根据九个工程的文件生成总目录中的 Excel 清单。此目录只保留生成脚本和使用说明；图片与 NDJSON 属于可重新生成的检查资料，已清理。

重生成前应关闭 Excel 中已打开的清单文件。脚本依赖系统捆绑 Node.js 和 `@oai/artifact-tool`，原依赖目录链接已移除，避免把共享运行时混入项目；需要重生成时，可由维护工具在本目录创建到当前捆绑 `node_modules` 的链接再运行。

工作簿已重新生成并验证，包含 HookWeightModule 分析结果的新位置，以及 AD7682 上位机源码和运行说明。总览第 16 行起为上位机说明区，文件明细列出各模块及测试文件。
